## 🇬🇧 English

### 📌 Project Overview
An interactive Business Intelligence (BI) dashboard built to process structured operational data, track key performance indicators (KPIs), and generate automated visual insights to support strategic decision-making.

### ✨ Key Features
- **KPI Metrics Tracking:** Real-time calculation of total revenue, average order value, and volume metrics.
- **Interactive Visualizations:** Dynamic charts powered by Plotly and Streamlit for multi-dimensional data analysis.
- **Data Filtering:** Custom filters to drill down into specific categories, regions, or timeframes.

### 🛠️ Tech Stack
- **Data Processing:** Python (Pandas)
- **Dashboard Framework:** Streamlit
- **Data Visualization:** Plotly
- **Version Control:** Git & GitHub

## 🇪🇸 Español

### 📌 Descripción del Proyecto
Dashboard interactivo de Inteligencia de Negocios (BI) desarrollado para procesar datos operativos estructurados, realizar seguimiento de indicadores clave de rendimiento (KPIs) y generar visualizaciones analíticas automáticas que apoyen la toma de decisiones estratégicas.

### ✨ Características Principales
- **Seguimiento de KPIs:** Cálculo en tiempo real de ingresos totales, valor promedio de transacciones y métricas de volumen.
- **Visualizaciones Interactivas:** Gráficos dinámicos impulsados por Plotly y Streamlit para análisis multidimensional.
- **Filtros de Datos:** Segmentación personalizada por categorías, regiones o periodos de tiempo.

### 🛠️ Tecnologías Utilizadas
- **Procesamiento de Datos:** Python (Pandas)
- **Framework de Dashboard:** Streamlit
- **Visualización de Datos:** Plotly
- **Control de Versiones:** Git & GitHub
